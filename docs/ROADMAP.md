# Coordinated roadmap

All milestones below are **PLANNED** and require separate implementation authorization. UI-1.2K memory/text/vector investigations and external acceptance gates remain open. No feature is claimed implemented by a planning document.

| Milestone | Planned capability | Main dependencies |
|---|---|---|
| KH-1.0 | Intelligent Khatma planning | Exact source identities; explicit plan inputs and progress |
| KH-1.1 | Adaptive recovery | Deterministic confirmed-progress accounting |
| KH-1.2 | Smart reminders | User preferences; device-local notification registrations |
| KH-1.3 | Exact resume | Stable reading-position/source-anchor services |
| BM-1.0 | Animated physical ribbon bookmark | Same ayah/anchor services as KH-1.3; separate saved bookmark identity |
| LAN-1.0 | Local-first desktop/mobile synchronization | Shared positions, causal progress/plan changes, bookmark identity, pairing/security and future mobile-platform research |

Last viewed position, explicitly saved ribbon identity, ordinary bookmarks and confirmed completed Khatma ranges are related but distinct. Viewing, selecting, scrolling, bookmarking or synchronizing never proves completed recitation. Layout coordinates/adaptive leaf numbers are not durable identities.

The detailed existing proposals are preserved with only workstation-path and private-evidence-link redactions: [Khatma](roadmap/khatma/DEFERRED-KHATMA-PROPOSAL.md), [BM-1.0](roadmap/bookmarks/BM-1.0-ANIMATED-RIBBON-BOOKMARK.md), [LAN-1.0](roadmap/sync/LAN-1.0-LOCAL-MOBILE-SYNC.md). Their product requirements are unchanged. After current stabilization and required separate authorization, begin with shared stable identity/confirmed-progress contracts before feature implementations. No mobile framework, network listener or background service is chosen or enabled.
