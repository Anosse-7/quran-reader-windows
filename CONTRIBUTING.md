# Contributing

Contributions, forks and independent development are welcome. Discuss significant architecture or rendering work in an issue before a large change. Keep patches focused and explain the problem, resulting behavior, tests and remaining limitations.

Submit only code you may contribute under this project's MIT License. Preserve third-party notices. Do not upload publisher databases, Tafsir archives, font files, protected artwork, user databases, heap dumps, traces, personal paths or private screenshots. Redact reproducible reports and use synthetic non-scripture fixtures where appropriate.

Never fabricate, normalize, trim or silently correct authoritative scripture. Preserve source Unicode and stable ayah identities. Keep content access read-only and pins intact; missing or invalid resources must fail visibly. Viewing, selecting or bookmarking must not count as completed recitation.

Maintain separate interface/domain/data/user-state responsibilities, native RTL accessibility, diacritic clearance, source-bound Tafsir and stable reading anchors. Do not suppress unexpected UI exceptions or weaken a memory/geometry/pixel gate. Provide tested revisions and label unexecuted native/DPI/specialist checks honestly.

Run the README's locked build and unit commands. These public asset-independent tests do not replace the private content integrity or native acceptance matrix. New features in the roadmap remain planned until separately authorized. See CODE_OF_CONDUCT.md for community expectations.
