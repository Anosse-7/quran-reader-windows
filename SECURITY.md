# Security and privacy

This project is experimental and has no supported production release. Do not use an issue to publish exploit details, credentials or user/heap data. Use GitHub private vulnerability reporting if enabled; otherwise open a minimal issue requesting a private contact without disclosing the vulnerability.

Reports should include the source revision, affected component and a minimal redacted reproduction. Do not include protected content or private diagnostics. No guaranteed response time is promised. Do not add network listeners, cloud dependencies, telemetry, broad permissions or silent elevation as incidental changes. Local synchronization remains planned, not implemented.
